Développeur Full Stack MERN – Stage de fin d'études (6 mois)

Stage 6 mois 💼 Temps plein (35h) 🏠 Télétravail partiel (2j/sem) 📅 Démarrage : Septembre 2026 💶 1250 € / mois + Swile & Navigo

📄 Missions du stage

Intégré à l'équipe tech de DataPulse Solutions et sous le tutorat d'un Senior Developer, vous interviendrez sur l'ensemble de la stack logicielle (React, Node.js, Express, MongoDB) :

  • Développement d'APIs RESTful : Confection et sécurisation des endpoints sous Node.js / Express (validation Zod, authentification JWT, streaming de flux de données).
  • Modélisation et requêtage MongoDB : Structuration des collections, agrégations avancées et optimisation des requêtes de monitoring logistique.
  • Interfaces réactives React & Tailwind : Développement de dashboards temps réel, tableaux modulaires et visualisations interactives.
  • Tests et intégration : Écriture de tests avec Jest et React Testing Library, revue de code sur GitHub et CI/CD.

🔎 Profil recherché

Étudiant(e) inscrit(e) en cursus Développeur Fullstack MERN (Promo 2026/2027) à la recherche d'un stage de fin d'études validant le titre.

🎯 Compétences requises

  • Solide maîtrise de JavaScript (ES6+) et React
  • Bonne compréhension de Node.js et Express
  • Bases solides NoSQL (MongoDB / Mongoose)
  • Pratique de Git & gestion de branches

🌟 Atouts appréciés

  • Notions de TypeScript
  • Familiarité avec Docker en local
  • Rigueur, curiosité et esprit d'équipe

</> Technologies demandées

React Node.js Express.js MongoDB TypeScript Tailwind CSS Git / GitHub Jest
